# 纸样

当前尚未生成本项目原创巡猎衣身纸样，但已取得创作者的 40 cm 坐姿卫衣参考版，原图位于本地 `../references/local/patterns/panda-sitting-40cm-hoodie/`。出处、A4 打印说明及适配检查见[现成纸样研究](../existing-pattern-research.md)。可以先用衣身和袖片做围合比较，再建立巡猎版本；它还不是经过验证的万代三月七版。

- 源文件可采用 SVG、DXF 或实际使用的打版软件格式，导出打印版用 PDF／SVG。
- 统一使用 mm，说明纸张尺寸、拼接方式与 100%／实际大小打印设置。
- 每版必须包含标注边长的校准方框（可采用 50 × 50 mm），打印后用尺核对。
- 裁片标注名称、版号、裁剪数量、左右／镜像、布纹、对位点、折线和开口。
- 写明是否包含缝份，各边缝份分别多少；缝线与裁剪线区分清楚。
- 写明目标娃体、量体表版本、面料条件与实测状态；未试穿文件名加 `draft`。
- 改版保留旧版与 [制作记录](../build-log.md)，记录修改量与原因。

文件名示例：`bodice-v0.1-draft.svg`、`pattern-v0.1-draft-a4.pdf`。以上仅为命名示例，文件尚未生成。
