单片保留原净缝线、裁边、尺寸、数量、纹向、对位记号及 50 mm 校准线。底色／渐变延伸到裁边覆盖缝份，金边根据真实净轮廓内退，卷纹单独放在可见区域；没有把旧矩形样块整幅压缩成衣片。

C01 为深胸双卷；R01 为红衣前缘浅金纹；R03 为可选平面肩纹；R04 **本图显示里侧暗纹，表面使用净红色**；S01、S02 分别为大侧卷和前小卷；B03 白袖局部为淡粉花边；W03 蓝尾为浅色边与渐小花纹。白衣身、后背未知区域、隐藏贴边、粉白衬摆不加无关纹样。左右展开是本版工程排位，不作为官方背面或左右对称的证明。

这是帮助核对“衣片是什么、图案在哪”的看稿，不是厂家可直接印制的生产文件。缝线／文字仍在图上；原[1:1 结构 PDF](../hunt-full-pattern-v0.2-1to1.pdf)和[完整组装说明](../assembly.md)保留。生产图需另导出无工艺线的版本，并在试坯和材料小样后确认花纹尺度、对花与缩水。

## 每片材质标注

单片SVG下方增加材料建议区，总览卡片直接列出中文材质、组号及目标克重。单片还记录面布、里布、贴边／支承布、局部衬的颜色／工艺与位置，均为尚未打样的建议。说明区只增加页高，原衣片坐标、毫米比例和50 mm校准线保留。数据来自[逐片材料记录](../piece-materials.json)。
