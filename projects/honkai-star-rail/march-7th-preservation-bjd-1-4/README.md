# 三月七·存护公式服／四分 BJD

- 状态：官方模型已下载；基础试坯 v0.1 已生成，待实物试穿。
- 造型：原始存护造型／公式服。
- 目标娃体：UFdoll 四分囡囡体 S 胸（用户指定）；品牌发布记录已核对，实物版本与尺寸待复核。
- 制作条件：可关节活动的四分 BJD；胸型固定为 S 胸。
- 已有产物：官方立绘／动作参考、官方 PMX 参考模型、基础试坯 A4 PDF／SVG／参数与检查记录。尚无实物验证。

## 制作目标

先验证衣身、袖窿和穿脱开口，再增加造型层与装饰；需要检查抬臂、屈肘和坐姿。

用户可以缝纫、缠花并使用自有 3D 打印机。服装主体优先采用布料制作；配饰按参考效果、安装与重量，在缠花、打印或组合工艺之间选择。具体部件清单待官方参考拆解后确定。
