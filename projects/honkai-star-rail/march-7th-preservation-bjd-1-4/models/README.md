# 配饰模型

当前为空，等待配饰结构与安装位置确认。保存自主制作的配饰、底座及连接件；原始参考模型放在忽略提交的 `../references/local/official-models/`。

- 保存可编辑源文件，例如实际采用的 Blender、FreeCAD 或 OpenSCAD 格式。
- 分享打印件时同步保存对应版本 STL／3MF，并在说明中标明单位 mm 和包围盒尺寸。
- 记录对应部件、目标娃体、安装位置、缝线孔或连接结构，以及试装结果。
- 打印机类型、喷嘴／设备分辨率、耗材与参数确认后再填写，不预设设备。
- 每版记录实际材料、重量、支撑／方向与成败；先打印尺寸或连接小样。
- 接触娃体、布料及丝线的边缘在试装时检查挂丝、摩擦和压痕。
- 未打印或未试装的模型使用 `draft` 标记；源模型和导出件保持同一版号。
- G-code 留在本地，不作为通用模型发布。

缠花本体的工艺记录写入 [制作记录](../build-log.md)；若有打印底座，保存在此目录并相互链接。
