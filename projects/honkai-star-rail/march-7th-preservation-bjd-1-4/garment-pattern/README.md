# 存护三月七：完整衣片试版 v0.2

## 尺寸依据

[DOLK 囡囡体 S 胸商品页](https://dolk.jp/portal/itemDetail/?ItmID=215136&breadcrumb=no)转载厂家标称：胸围170、腰围128、肩宽86、肩到腕122 mm。资料来源详见[量体档案](../measurements.md)。这些不是用户实测。

用户已授权按囡囡体维度估算。当前设计取：成衣胸围180（松量10）、腰围140（松量12）；袖窿深36、肩颈到腰78、衣长86、袖长108＋袖口14、净袖口围50；裙长86。后五项及所有外搭、饰片、蝴蝶结长度属于**设计估算**。初版白衣和腰层都按净腰140设置，实做若叠层过紧可先放大独立腰带，不能靠拉紧魔术贴解决。

## 六层分别是什么

1. **白色内衣层 B01–B08**：完整白前身、左右后片、左右长袖、宽袖口、前翻领、领口包边、后中贴边和袖底开衩薄条。前身两个5 mm腰省、两后片各一个5 mm腰省形成收腰；前中仅装饰，真实开口在后背。
2. **露肩蓝外搭 O01–O07**：有独立前身、两后片、两只蓝外袖、前腰系带、袖尖垂片和蓝紫上臂翻片。外搭上缘在肩下，靠白内衣四个隐蔽固定点承托，不做成普通肩部全盖住的T恤。蓝袖下缘自由，白袖穿过，袖尖垂片另缝到外侧。
3. **深蓝披领 C01–C02**：左右前长尖领＋左右后宽尖领，各配薄里。前后片的16 mm短边相接后搭在肩部，数处暗缝定位；背中仍分开。双白条是按成品外缘安排的后续印花。
4. **褶裙 S01–S03**：真实长裙片420×86；14个30 mm重复折成每褶10 mm，腰口变成140。腰头150×12，只有最后10 mm为后扣搭接。裙后缝上端30 mm开衩，边对边闭合；另加护片，不从裙围再扣10 mm。
5. **深色腰饰 W01–W04**：穿衣者右前较短、左前较长、左右后片向中央弯收，四片上端各35 mm装到独立淡紫带；侧下边自由。装饰带闭合140，独立后扣。所有腰片上端与裙腰头上缘同高：裙含腰头总长98，长腰片86，距裙底12 mm。实际相机和扣件位置试装后再微调。
6. **可拆背蝶结 A01–A05**：双翼面里、结芯面里、左右不同长度垂尾、针座承力底片、衣服单侧承力片都有轮廓。针座缝在结背承力片，活动针只别衣服一个后片；避开魔术贴，先摘结再穿脱。

## 看线和裁剪

- **黑实线**：已经包含缝份的裁剪边；**红虚线**：净缝线／成品边。一般拼接外偏5 mm、小件翻缝外偏3 mm，使用几何等距外扩，不是把整片缩放。
- 青色线是省道、对位、折褶或后中参考线，不作为剪开线。前后省道缝到尖点，不沿标线剪开。
- 净尺寸、裁片尺寸是曲形衣片的外包框，必须沿轮廓裁剪。镜像裁片必须一左一右，不能两片同向。
- B06、B08按45度斜裁；袖口、腰头、腰带和结芯长向顺纹；裙和其余大件以图示长向为经向。面里使用同轮廓；小样若需减里请另记改量。
- PDF是一片一页的全幅1:1文件；裙片所在页面较宽。按100%输出或用打印软件海报分页，关闭“适合页面”。先量50 mm校准线；不要按预览图片的显示大小裁剪。
- 图中肩宽、胸围、腰围等不是每个外包框数字相加。背片含净搭接5，闭合后总搭接10需扣除；腰线还要扣四个5 mm省量。

## 建议组装顺序

1. 白衣先缝四个腰省（前身2＋后身各1），合肩缝、侧缝。前翻领按左右前领口各26 mm定位，B06包净完整领口（包含两段前翻领根部，净连接长139.5 mm）；不可只包剩余领段，也不要把前翻领片缝到后背。
2. 袖山前段对前袖窿、后段对后袖窿，各1 mm吃势，共2 mm；剪口按实际弧长的一半放置，对应前后每半段0.5 mm。先固定袖山顶和剪口，再均匀分配吃势。合袖底但末15 mm保留，用B08包净。
3. 白袖摆70 mm抽褶到50 mm接袖口；袖口末10 mm搭接，装小段6 mm软薄魔术贴。袖口50是估算，手不拆卸时须检查能否通过；不能通过先加大开衩/袖扣再裁正式布。
4. 白衣后中接B05贴边，沿原后中对齐闭合；每片净延伸5形成总搭接10。下搭朝外细勾，上搭朝内软毛圈；扣位局部加薄衬，内侧遮针脚。
5. 蓝外搭面里分别合侧缝；前后低袖窿接蓝袖，前后各1 mm吃势。先将O04两系带的16 mm端缝进前中，其他自由边与薄里翻净。O05在外袖下摆外侧接24 mm，O06顶边50收至衣身袖窿接缝47.835，收量2.165，沿完整接缝一圈外侧定位；蓝袖山自身2 mm吃势另外分配（见geometry-checks）；露肩区域保持开着。
6. 深蓝领前后各以16 mm顶边连接，面里翻净，数处暗缝定位。外搭前后顶点(40,26)与蓝袖山顶三片交汇：先将前、后袖山分别缝至共同顶点，再用薄里封净该点；没有另设肩缝。O07四条支承：白衣每前/后片的(36,16)连接蓝片本侧(38,28)，左右镜像；20长的两端各3固定，中间14保留。外搭背扣独立闭合，这四处只固定本侧，不能锁住后开口。试穿时检查领、袖顶与肩部空隙。
7. 裙先做5 mm窄下摆，再折14褶：每个30 mm区段的两条线间折进20，只留10 mm褶面；先纸上试折一段核验。后边净缝线对齐合缝至距离上端30，开衩各边用已有5 mm缝份收净，护片只接一侧。140 mm褶后腰接腰头前140段，末10保持悬空作搭接。
8. 腰饰分别面里翻净，四个35 mm顶边按腰带0–35（左后）、35–70（穿衣者左前长片）、70–105（穿衣者右前短片）、105–140（右后）定位；这是从一侧后中沿腰一周的区间。末10 mm为后扣，裙和腰饰独立穿脱。
9. 背蝶结双翼翻净、中央捏褶，双尾各收褶到12，收入结芯背面。结芯26扣除4搭合形成22环长；若叠层过厚先延长结芯。针座布底和衣身支承片按图先做，金属针座实际长度以结背能遮住及可操作为准。

## 印花如何继续落到完整衣服上

现有 `fabric-print/` 的S01–S12是纹样来源，不作为衣片。确认这轮试版后，裙边映射到P-S01，披领映射到P-C01/C02，蓝紫色场映射到P-O01–O07，长尾映射到P-A03L/R，深色腰片映射到P-W01–W03。底色覆盖本轮净线外的缝份，白边／金边仍按**成品边**定位，不随裁边外移。工艺线留在独立校对层，不能印进可见衣面。

当前已验证：所有净片与裁片多边形有效、裁片完整包住净片；肩/侧/袖山配对、袖山分段吃势和裙腰关系通过数字核对。尚未验证：S胸立体曲面贴合、袖窿活动、手掌通过、腰层厚度及实布缩水。完整衣片方案已出，定位印花母版要在试版修改后再定稿。

## 再生成

执行 `python3 tools/create_preservation_garment.py`；需要 Shapely、ReportLab、PyMuPDF、fontTools，以及可调用 sharp 的 Node。脚本优先读取仓库忽略目录 `tmp/garment-python` 的依赖。此版参数文件是固定尺码的设计记录，尚不是任意改胸围即可自动推码的工具；改娃体尺寸时应同时编辑对应轮廓并重跑配对检查。
