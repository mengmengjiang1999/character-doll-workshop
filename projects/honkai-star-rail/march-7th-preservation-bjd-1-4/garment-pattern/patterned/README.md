# 存护完整衣片花纹预览

[分层前后与合穿](layers-overview.png) · [30片花纹尺寸图](pieces-overview.png) · [逐片SVG](pieces/)

本目录在v0.2实际衣片轮廓上直接显示花纹和编号，原净线、裁线、尺寸与PDF没有改动。底色延伸至原裁剪边，装饰白边、金边按成品边向内定位。所有字、编号、缝线均为校对内容，不能将本预览直接交厂印布。

披领双白条、裙白宽边/细线/菱形/四瓣、袖口蓝线、上臂翻片蓝紫渐变、背结尾蓝粉渐变和腰饰金边来自现有自主绘制花型并按新轮廓重新定位。紫粉集中在肩翻片，蓝衣身保持浅蓝；未见背部纹样不由正面复制。白内衣、薄里、隐蔽支承保持净色。

裙展开每30mm重复中的前10mm暂定为可见褶面，菱形和花形居中置于这些区域；仍须纸折和试布确认最终褶向。合穿图中花饰、扣位为外加配饰的定位示意，不代表要印在白衬衣或支承片上。

图中P-B01等编号与[原完整衣片清单](../pattern-manifest.json)一一对应。[检查记录](preview-checks.json)核对30片原SVG路径均保留；尚未实物试穿或印样。
