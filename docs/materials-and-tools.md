# 材料、工具与工艺选择

以下是选材与试样框架，尚非两套三月七服装的最终采购清单。

## 已有能力

- 可以采购布料、针线及常规辅料；具备缝纫能力。
- 具备缠花制作能力，可制作头饰或配饰。
- 已有 3D 打印机；型号、FDM／光固化类型、现有材料与可用参数待登记。
- 可查找官方立绘、视频和公开发布的模型作为参考；模型具体使用范围以对应发布页与随包说明为准。

## 工艺分工候选

| 部件需要 | 优先试样方向 | 实物检查 |
| --- | --- | --- |
| 衣身、软质层、带状或垂坠结构 | 缝纫、手缝、包边或贴布 | 厚度、垂感、缝边体积、穿脱与活动空间 |
| 适合丝线质感的装饰 | 缠花；先做单个组件 | 轮廓、比例、毛边、重量和固定方式 |
| 需要稳定几何外形的装饰 | 3D 打印后处理 | 可打印细节、表面、尺寸与佩戴重量 |
| 缠花需要的定位底座或装饰支承 | 打印底座＋缠花表层 | 连接结构是否藏得住、是否易拆修 |
| 与衣物相连的配饰 | 设计缝线孔、底座或其他可拆连接 | 拆装后是否松脱、勾布或挤压娃体 |

以上分工是本项目候选方案。先核对角色参考，再决定哪些部件存在、由哪种工艺完成。

## 布料与辅料：先样片，再定量

- 先列每块材料需要的颜色、光泽、厚薄、弹性、垂感与用途，再选实物样片。
- 用样片做缝边、叠层、包边和装饰固定测试；记录对娃体或浅色内搭的接触染色情况。
- 松紧、暗扣、粘扣、系带等开口方案通过穿脱小样选择，尺寸待量体与开口确定后填写。
- 纸样通过白坯验证后，按布幅、方向性、裁片排布和预留试样计算采购量；现阶段不预填米数或批量采购。
- 缠花材料先复用已有线材、骨架与工具；通过单件样品后再统计整套数量。

建议每种材料记录：`用途 / 候选材料 / 现有库存 / 样片结果 / 需购数量 / 实际用量 / 来源`。

## 3D 打印材料：按设备与部件选择

### 本轮建议（2026-11-03）

用户表示材料可以购买，希望比较哪种工艺更好做；尚未确认现有打印机类型。以容易试制和修改为目标，本轮建议先用 **FDM＋PLA** 检查额饰轮廓、相机外壳和底座比例；精细花纹、细小金属饰件与光滑饰面可再考虑光固化树脂，丝线质感保留缠花工艺。这是制作建议，不代表用户已选择设备或已经打印成功。

PLA 的易打印特性依据 [Prusa 材料说明](https://help.prusa3d.com/article/pla_2062)；树脂的细节／表面优势依据 [Prusa 树脂指南](https://help.prusa3d.com/article/resins_1977)。光固化还需配套清洗、后固化与液态树脂处理，流程参考 [Formlabs 后处理说明](https://formlabs.com/support/3d-printing-post-processing-faqs/)。当前不因此购买设备，也不预填温度、层高或曝光参数。

| 条件 | 材料候选 | 依据与验证要求 |
| --- | --- | --- |
| FDM；细节装饰或尺寸试样，不承担反复受力 | PLA | Prusa 将其用于精细模型和快速原型；仍需验证实际细节与脆弱部位 |
| FDM；底座、支架或需要一定韧性的连接件 | PETG | Prusa 列出其韧性与机械件用途，同时指出细节表现有限；先验证连接结构与表面效果 |
| 光固化设备 | 按现有设备和树脂厂商指南选型 | 设备未确认前不指定树脂、曝光、清洗或固化参数 |
| 材料或设备尚未确认 | 保留设计与打印试样任务 | 不把候选材料和切片参数标为已验证配置 |

材料性质的一手来源：[Prusa PLA 指南](https://help.prusa3d.com/article/pla_2062)、[Prusa PETG 指南](https://help.prusa3d.com/article/petg_2059)、[Prusa 材料比较表](https://help.prusa3d.com/filament-material-guide)。查阅日期：2026-11-03。上表将材料性质对应到娃衣部件，是制作方案推断，不是厂商对本项目的认证。

不直接照搬文档里的机器温度。每个打印件分别记录设备、材料品牌／型号、单位、方向、层高、壁厚、支撑、后处理、实际尺寸与重量，使用匹配设备和材料的设置并先试样。
