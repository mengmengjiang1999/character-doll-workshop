# 三月七完整衣层：参考复核与打版边界

复核日期：2026-11-03。本轮目标是给出完整服装的分层外形和有尺寸的衣片试版，原来的装饰纹样库继续作为定位印花素材。这里记录已经看见的服装形态，并把娃衣制作结构单独说明。

## 存护：完整外形必须保留什么

| 衣层 | 可见外形 | 本轮娃衣结构应体现的内容 |
| --- | --- | --- |
| 白色内层 | 胸身合体、前中有扣饰、宽开领翻领；白袖较宽，袖口明显翻折 | 有肩斜、领口、袖窿及收腰的前身和两后片；真正的长袖片、翻袖口、领片和后开口贴边。胸部容量可由省或分片提供，不能用直筒替代 |
| 蓝紫外搭 | 前胸敞开；前端在腹部打结；肩部有蓝紫翻片；上臂至肘上仍有蓝色外袖，下面才露出白袖 | 外搭前后身、前系结端、蓝色外袖、肩翻片及需要的薄里。不能只出披领，也不能变成普通闭合短背心 |
| 深蓝披领 | 背面左右各有宽尖片和双白条，中间留出花饰位置；前面呈垂落的窄尖轮廓 | 左右独立领面及里片，按真实连接边落位。背部不是普通整方水手领；为后开口断开属于娃衣结构选择 |
| 深蓝裙层 | 裙摆有实际立体褶量，成品轮廓向外展开，下摆宽白边和细白线 | 裙片、完整褶位、褶后腰线、独立腰头和后开衩；褶数与深度是本轮设计参数，不能从模型材质线直接认定 |
| 深色腰侧覆盖层 | 前后均有长短变化与弯曲下缘；较长尖端接近裙摆，左右遮挡关系受相机影响 | 不等长的腰侧片与薄里、单独安装带；不能用两块等长长方片代表全部轮廓 |
| 背部蝴蝶结 | 位于背部披领之间下方，蓝色翼与蓝粉渐变长尾分明 | 完整结翼、结芯、两尾和背面承力底片。按用户决定装可拆别针，针座只连到衣服一侧加固区，避开魔术贴 |

白内搭、蓝外搭拆成两件是便于试穿、印制和缝制的方案。模型能证明可见白色/蓝色层次，不能证明游戏作者设计了一件可以单独脱下的白衬衣。试版说明应写清这一点，同时仍给白内搭完整衣片。

背部蝴蝶结可以从外观上遮住后中，但活动针与承力底片不能跨两后片。蓝外搭、白内搭、裙腰应各自可打开，不把几层的门襟一条线缝死。腕部小结、胸饰、相机等另作配饰，不用于代替主体衣片。

## 巡猎：完整外形必须保留什么

| 衣层 | 可见外形 | 本轮坐娃结构应体现的内容 |
| --- | --- | --- |
| 浅色领口与深色胸身 | 浅色领缘从颈部向胸前汇合；深褐胸身具有弧线而非矩形胸章，腰部收窄 | 具有肩、领、袖窿、腹部容积的基础前后衣身；深色胸面可用分片或薄贴片实现，但必须有真实承载衣身 |
| 白袖与粉边 | 白袖具有蓬量；外侧可见淡粉花边，靠上位置另有粉色翻起的褶/荷叶轮廓，腕部收束 | 宽白袖、独立粉色褶边或荷叶边、袖口及可开下袖缝。不能把花边印在直筒上就算完成袖子 |
| 红色外搭 | 红色短肩袖覆盖上臂；开襟边弯曲；袖口下方/后侧有继续向外延伸的长尖飘片，里侧为较深红色 | 红前后身或肩身、短外袖、独立尖尾/飘片、门边及里片。保留前短、侧后长的视觉层次，不画成一件均匀齐腰上衣 |
| 深色裙瓣 | 前方较小、侧方较大的分瓣覆盖层，弧形/尖角边缘与金色边纹共同构成轮廓 | 有造型的前裙片、侧裙片及薄里，挂在独立腰头上；坐姿时边缘分开、腿间留空间，不把每瓣侧边缝成窄筒 |
| 粉白内摆 | 深色裙瓣下面确实露出粉白褶/荷叶边层；并非只有外裙上印一圈白线 | 完整浅色短衬摆和粉色褶边。坐娃可采用前短后分片的柔软结构；它是坐姿适配设计，不据立绘断言原服装下装拓扑 |
| 蓝/粉腰带 | 蓝带斜向交叉并在前中扣饰处汇合；粉带横向环绕并形成侧垂花结，二者不是同一走向 | 分开的斜蓝带、横粉带、独立结/长尾、各自固定点；与衣身开口分离，避免勒住腹部 |

立绘中局部浅色下装不能据单一透视图确定整条短裤的形状。若试版只覆盖衣身、裙瓣和短衬摆，应明确范围，不将其称为已经还原原角色全部内搭。手套、靴、丝袜、头饰、双剑另做，不用这些配饰补足缺失的主体衣服。

当前巡猎背面衣片可以按可穿脱需要设计：后中开口、独立贴边、分层背扣，以及坐姿下不会压住的下摆。这些应标作**背面制作方案**。不得把正面卷纹镜像到背面，并宣称它是已核验的官方背面。

## 尺寸与核对方式

- 囡囡体已有标称胸围、腰围、肩宽等；未提供的前后腰节长、袖窿深、上臂围等必须作为独立设计假设列出，不能与实测混在一栏。方案可以给出实数首版衣片，但不能声称已经合身。
- 万代坐娃缺少可靠实测围度。数值首版必须有明确可替换的假设体型输入，不从 380 mm 标称高度反推胸腹围。更换输入后要重算衣片与所有相邻接缝，而非整套等比例缩放。
- 每层至少展示前、后外形；分件图应能对照衣层编号，显示哪些是主体、哪些是里片或贴边。蓝外袖、红尖尾、粉白内摆等轮廓不能在总览中消失。
- 每片分别记录净形、缝份外扩后的裁剪边、数量、面料/里料、纹向、后开口/折线及接缝对象；凹曲线不使用统一放大代替缝份外扩。
- 检查肩/侧等配对缝线长度；袖山吃势、裙褶收量、弯领口接合另列数值。纸面检查通过不替代同材料试坯与娃体试穿。

新试版的衣片负责形体，原 `fabric-print/` 的图案负责随后定位；边纹对准最终成品边，底色延入缝份，背扣隐藏区不放主花纹。完整衣片定版后再按不同面料分幅输出印布文件。
