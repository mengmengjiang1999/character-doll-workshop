# 彩色布料印花交付与打样

当前目标是照三月七两套公式服重绘布料上的颜色、渐变、边饰和定位纹样，后续由厂家印布。当前文件是**纹样打样布局**，尚未按实际衣片定版；不是缝纫纸样，也不是已经通过实物验证的生产排版。

完整服装的分层与数值衣片已另存于两项目 `garment-pattern/`，可从[打版册](garment-guide.html)逐层查看。先用该版确认穿脱与轮廓，再把现有纹样按调整后的净缝线定位；带工艺线的试版图和旧纹样总版均不直接视为最终生产印布稿。

## 文件与尺寸

已增加 `dimensions-overview-v0.1.svg/png` 与 `dimensions-components-v0.1.svg/png`，分别标明整版、各组件宽高和毫米单位。标注来自现有 SVG 画布与 manifest；含留白，不代表最终裁片。**尺寸图用于沟通，请不要把箭头、编号和文字一起印到布上。**

按[部位选材表](fabric-selection.md)及各目录 `fabric-plan.json` 分布料询样；原整版是综合花型总览，最终定布后需要按材质分别排版，不能默认全套同布印制。

新增的[拼接与背开口规划](seams-and-back-closure.md)会作为正式定位排版的依据：先完成净衣片和后中搭接，再加缝份与所需印花延伸。印花出血不等于缝份，魔术贴搭接净宽也不能由普通缝份代替。现有图案块未因此变成完整可缝衣片。

- **SVG**：可编辑母版，保留独立纹样，方便后续按实际部件调整尺寸和位置。
- **PDF**：按画布毫米尺寸输出的 1:1 校对／交接稿；查看或打印时用 100%，关闭适合页面。是否接受作为生产文件由厂家确认。
- **PNG／TIFF**：默认按实际画布 300 ppi 导出，嵌入 sRGB ICC；生产位图扁平化并显式给出底色。文件以各项目 `manifest.json` 为准。
- **对应说明／清单**：记录纹样对应部位、可见参考、画布和图像尺寸、待确认项；校对标签、裁剪线、尺寸文字不混入生产印花图。

## 厂家规格并不统一

本仓库的 300 ppi 是保留细节的导出约定，不是行业统一标准。例如 [Prinfab 官方指南](https://prinfab.com/resources/guidelines)对面料建议 180 DPI、RGB、嵌入 sRGB 配置、扁平无透明的 JPG／PNG／TIF 等；[Contrado 官方指南](https://www.contrado.com/contrado-starter-pack)建议按 100% 尺寸准备 200 DPI 图，复杂图可用扁平 TIFF。

保持当前 sRGB 源稿，**不要因为“要印刷”就盲转 CMYK**。先确认厂家的文件格式、目标色彩配置、透明处理和有效印幅；确需转换时，按该厂提供的配置从母版另导出。不能通过只改 DPI 数字补足低清参考图的细节。

## 打样时确认什么

1. **尺寸和排列**：上传后再次核对毫米尺寸。定位花型按单张布局输出，关闭自动重复、自动铺满和适合幅宽；如需拼版，先确认拼版后的尺寸和方向。Prinfab 提醒客户自行检查尺寸、位置与重复方式，并说明所需裁切／折边余量应包含在图稿中，不能依赖图外白边。[厂家 FAQ](https://prinfab.com/resources/faqs/)
2. **颜色和细节**：使用最终候选布料，先印包含主要色块、渐变、最细线条和小纹样的样布，在一致光线下确认。布底色、织纹、反光和工艺会改变呈色；不同布料、批次可能需要分别校色。屏幕色和从官方参考采样得到的色值不等于成布标准色。[Contrado 色彩指南](https://au.contrado.com/faq/82)
3. **纹样位置和布纹**：当前布局用于看花型。生产定版时，按实际衣片确认正反、左右、布纹方向、缝合与折边范围、褶量和相邻片对花。游戏 UV 图块的比例与排布服务于三维模型，不直接对应娃衣实体衣片。
4. **缩水和出血**：记录选定布料印制／后整理后的经纬向尺寸变化，再确定补偿；出血和裁切误差按厂家工艺与实际衣片确定，不统一套数值。Contrado 所列 2–8% 潜在缩水是其面料提示，不能当作本项目已测结果。[厂家说明](https://au.contrado.com/faq/82)

图中的“金色”默认只是普通彩色印花效果；需要金属光泽时，另与厂家确认工艺，不能从屏幕预览推定。[Contrado 关于金属色的说明](https://au.contrado.com/faq/82)
