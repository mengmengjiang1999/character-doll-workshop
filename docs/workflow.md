# 从参考资料到实物验证

本流程用于角色娃衣、缠花配饰和 3D 打印配饰。当前已有囡囡体基础试坯纸样和巡猎额饰打印试件，均尚未实物验证；各项目文件标明具体版次与检查范围。

## 1. 确认对象与参考

- 固定角色、命途／服装版本、目标娃体，记录官方立绘、视频和模型来源。
- 分别收集正面、侧面、背面与局部视角；看不清的结构标为“待确认”。
- 三月七存护公式服对应四分 BJD；巡猎公式服对应万代坐姿棉花娃娃，两个项目独立量体、独立打版。
- 下载的官方模型用于观察结构时，记录具体文件、发布来源及随包说明。游戏模型观察结果仍需转成实物可缝制、可佩戴的结构。

## 2. 量体与穿脱方案

统一使用毫米（mm）。未知值标记“待测”，不用 0 代替未知值。身体实测值、设计松量、缝份分别记录。

每项记录：测量项目、数值、测点／姿态、是否穿内搭、日期、备注。测量两次并保留差异；用测点照片或示意图保证后续能复测。

| 对象 | 首轮需要确认 | 量体重点 |
| --- | --- | --- |
| 四分 BJD | 品牌、身体型号、胸型；头和手能否取下；目标摆姿 | 颈根围、肩宽、胸／腰／臀围、前后腰节长、上臂围、袖长、腕围、手掌通过尺寸、腰到目标下摆长 |
| 万代坐姿棉花娃娃 | 商品系列／编号；原衣可脱、局部缝合或一体；换装还是覆盖原衣 | 自然坐姿下腋下围、最大腹围、坐姿臀围、臂根间宽、前后衣长的表面弧长、手臂尺寸、腿间空间、坐姿占地宽 |
| 头饰／配饰 | 安装位置、可接受的固定方式、是否戴假发 | 接触面的长度／宽度／曲率、头围或佩戴路径、可用连接空间 |

棉花娃的量体方案以自然坐姿、软尺贴合但不压缩填充为准；按最终实际穿衣状态测。先确认开口能否通过头、手等部位，再确定领口和袖口。

需要裤装、袜套或鞋套时，再补裆长、腿围和足长宽。没有相关部件时无需一次收集全部数据。

量体方法参考：[Junice Dotseth《How to Measure Dolls》](https://www.junice.com/files/Wellie%20Wisher%20Measurements.pdf)。该资料来自娃衣纸样作者，提供测点定义；其中示例娃体及尺寸不适用于本项目，棉花娃方案须实物验证。

## 3. 拆解结构与安排工艺

- 为每件衣物编号，画出前后轮廓、分片、布纹方向、叠穿关系和开口。
- 每个配饰单独记录目标外观、尺寸、候选工艺、重量与连接方式；选择依据见 [材料与工具](materials-and-tools.md)。
- 逐件说明如何穿上、如何固定、如何拆下。先解决躯干包覆和活动空间，再增加角色装饰。
- 为尚无证据的细节保留候选方案，不把推测写成官方结构。

## 4. 白坯与改版

- 用低成本试样布制作基础衣身、袖子和开口；试样布的厚度、弹性应尽量接近计划用料。
- BJD 检查站姿、坐姿及选定的抬臂／屈肘动作；记录拉扯、卡住、衣摆上移的位置。
- 坐姿棉花娃检查能否自然坐稳、腹部是否受挤、背后是否堆布、衣摆是否垫在臀下。
- 每轮记录“版本 → 问题照片 → 修改部位与数值 → 复测结果”，不覆盖旧版。
- 纸样注明适配娃体、版本、裁片数量、对位点、布纹、缝份是否包含；打印稿附尺寸校准框并按实际大小打印核对。

## 5. 配饰样件与正式用料

- 先做一个具有代表性的缠花组件或打印件，验证比例、表面效果、重量和连接结构。
- 打印件保存可编辑源文件与导出文件；登记单位、模型版本、打印机、材料、切片参数和实测结果。
- 先做缝边、包边、装饰固定与叠层小样，再按排料结果采购正式用料。
- 正式制作时记录实际材料和工序；更换布料或固定结构后，复查受影响部位。

## 6. 成品验证与发布

| 阶段 | 交付物 | 通过依据 |
| --- | --- | --- |
| 资料／量体 | 来源表、测量表、穿脱方案 | 角色版本与目标娃体已明确 |
| 白坯 v0.1 | 样衣、问题照片 | 基础包覆和穿脱可行 |
| 改版 v0.2 | 更新纸样、修改记录 | 选定姿态下通过复测 |
| 配饰样件 | 单件样品、连接与重量记录 | 固定可靠，外观与佩戴可接受 |
| 成品 v1.0 | 衣服、配饰、制作说明 | 实物试穿完成，适配范围与限制已记录 |

只有通过对应实物验证的文件才标为“已验证”；草案、打印成功和穿戴成功分别记录。公开时仅发布已确认可分享的文件，并保留参考来源与适配信息。
