# 完整衣片花纹与材质看稿 v0.4

[打开带花纹打版册](garment-guide.html)。两套分层前后图、合穿图和全部 57 种衣片的预览直接显示公式服纹样；图上保留衣片编号，可与尺寸、裁剪数量和拼接说明对照。每张单片底部新增材质栏，总览和网页也按编号列出面布、里布、辅衬与目标克重；数据源为各项目 `piece-materials.json`，参见[材料目录](material-catalog.md)。

| 文件 | 用途 |
| --- | --- |
| 各项目 `garment-pattern/patterned/layers-overview.png` | 看每层前后外观、合穿关系和衣片编号，不按像素量尺寸 |
| `patterned/pieces-overview.png` | 对照全部衣片的花纹、净尺寸与裁片尺寸 |
| `patterned/pieces/*.svg` | 放大看各编号完整衣片上的花纹、裁边、净线、纹向与尺寸 |
| 原 `garment-pattern/*.pdf` | v0.2 黑白结构纸样，按 100% 输出；原净轮廓、缝份及 PDF 均未改动 |
| `fabric-print/` | 现有独立纹样来源与打样画布，仍保留原文件 |

存护包含披领双白条、裙边菱形与花形、袖口蓝条、上臂紫蓝色场、深色腰片金边和蓝粉垂尾。裙片仍保留完整折褶量，纹样按可见褶面定位。背部蝴蝶结仍采用单侧承力的可拆别针，后中魔术贴结构不变。

巡猎包含前胸双卷纹、红前襟浅金卷纹、深色裙瓣暗纹与金边、白袖粉花和蓝垂尾纹样。红衣尾 R04 的彩色单片显示暗纹里侧，外面保持净红；胸卷纹只出现在胸片，不复制到后背。未知后背采用既有工程设计，隐藏支承、贴边与素色衬摆不添加花纹。

底色延伸至含缝份裁边，边饰按净衣片成品位置安排。彩色预览中的尺寸和工艺线用于校对，不是可以直接印在布上的生产文件。当前尺寸仍为已说明的试版估算；实物试穿后需同步修改结构和花纹，检查拼接对花，再按不同面料排版并去除技术标注交厂打样。
