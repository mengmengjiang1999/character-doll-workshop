# 参考资料管理

每个项目使用独立的 `references.md`，避免混用同一角色的不同造型。

## 来源登记

至少记录：标题、发布者、原始页面链接、内容类型、所对应的造型、核验日期、能支持的观察、仍缺的视角。

- 官方立绘：记录网页入口；分清角色展示图与玩家二次创作。
- 官方视频：需要具体细节时补充时间戳，说明是正面、背面、侧面还是动作参考。
- 官方模型：分别登记发布页、实际下载入口、版本、作者署名和随包使用说明。
- 娃体／商品页面：用于确认型号和结构；标称尺寸只作为信息记录，打版仍使用实测。

页面内容无法读取、只有搜索摘要或转载线索时，明确写出核验范围。不要把未核实的网盘链接登记成官方模型来源。

## 本地参考文件

下载时保留原有说明文件。推荐存放位置：

```text
<项目>/references/local/
  images/
  videos/
  official-models/
  usage-notes/
```

该目录已被 `.gitignore` 忽略。需要公开某份素材时，先记录对应发布说明和所需署名，再决定是否加入仓库；链接记录可以先公开。

用户已说明可使用的官方公开模型为非商用参考。已下载存护三月七官方 PMX 包并保存随包说明；巡猎包的下载状态另见各项目来源记录。每个实际下载包分别登记其说明，不把一个包的条件套用到其他模型。

## 从参考到制作

| 标记 | 含义 | 例子 |
| --- | --- | --- |
| 观察 | 能从指定资料直接看到 | 某帧中的装饰位置，附时间戳 |
| 推断 | 参考没有完整呈现 | 背面开口的可能结构，等待其他视角 |
| 制作选择 | 为目标娃体选定的方案 | 在后背增设可穿脱开口 |
| 实测 | 已经做过并有记录 | 某版试坯在指定娃体上通过坐姿检查 |

游戏模型用于观察轮廓、层次和装饰位置。自行制作打印件时，另建适合目标娃体的尺寸、厚度、安装结构和可编辑源文件，记录试装结果。
